# Atlaspec Support

Atlaspec is a research release candidate. Support is community-based.

- **Questions and design discussion:** use
  [GitHub Discussions](https://github.com/tauptlab/atlaspec/discussions).
- **Reproducible bugs:** use the
  [bug report form](https://github.com/tauptlab/atlaspec/issues/new?template=bug-report.yml).
- **Feature and schema proposals:** use the
  [feature request form](https://github.com/tauptlab/atlaspec/issues/new?template=feature-request.yml).
- **Independent benchmark results:** use the
  [benchmark reproduction form](https://github.com/tauptlab/atlaspec/issues/new?template=benchmark-reproduction.yml).
- **Security or private conduct reports:** follow
  [SECURITY.md](SECURITY.md).

Please include a minimal Atlaspec document, exact command, Node.js version, and
renderer target when asking for technical help.
