# Media assets

`atlaspec-60s-demo.mp4`, its poster, subtitle track, and the public demo's Open
Graph image are generated from `scripts/render_launch_video.py`. The video is
designed for silent autoplay and uses only project-owned graphics and text.

The current cut covers semantic linting, deterministic compiler policy, the
one-time local holdout, and explicit evidence gaps. Spatial-analysis scenes
from the superseded cut were removed because they are outside Atlaspec 0.2.

These assets may be redistributed under the repository's MIT License. Benchmark
numbers shown in the video retain the evidence boundaries documented in
[`docs/LAUNCH_KIT.md`](../docs/LAUNCH_KIT.md).
